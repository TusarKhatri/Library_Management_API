Hackathon Project Problems:

1. Library Book Management API

Build a Library Management REST API where admins can manage a catalog of books and users can view and borrow books.

Requirements
	•	User authentication & authorization (Admin, Member roles)
	•	CRUD operations on books (Admin only)
	•	Members can:
	•	View catalog
	•	Filter books by author, genre, availability
	•	Paginate results
